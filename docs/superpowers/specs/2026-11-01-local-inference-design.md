Shared JSON contract (exact keys):

- Context: projectId, modelId, modelCreatedAt.
- `workbench/inference/get` -> InferenceState {checkpoints: Checkpoint[], runtimes: RuntimeInfo[], loadedCheckpointId: string, promotion?: Promotion, issues: string[]}.
- Checkpoint {id,name,createdAt,graphRevision,modelCreatedAt,task,format,byteCount,chatCompatible,input: {mode,features: string[],sequenceLength,imageWidth,imageHeight,imageChannels,classes: string[]}}.
- RuntimeInfo {id,name,available,reason?}. Runtime id pytorch; other options disabled with reasons.
- `workbench/inference/import`: context + name,filename,contentBase64 -> Checkpoint.
- `workbench/inference/load`: context + checkpointId,runtime -> InferenceState.
- `workbench/inference/predict`: context + checkpointId,runtime,prompt?,features?: Record<string,number>,imageBase64?,temperature,maxNewTokens -> Prediction {checkpointId,testId,text?,value?,label?,scores?: {label,value}[],device,durationMs,truncated?:boolean}.
- `workbench/inference/promote`: context + checkpointId,runtime,testId -> Promotion {id,projectId,modelId,modelCreatedAt,checkpointId,name,runtime,createdAt}.
- `workbench/inference/unpromote`: context -> {ok:true}; unload -> InferenceState.
- Parent-owned chat helpers: Engine.LocalWorkbenchModels(ctx,provider) ([]protocol.Model,error); Engine.WorkbenchLocalPromotion(ctx,id) (workbench.Promotion,error); Engine.GenerateWorkbenchLocal(ctx,id,prompt,maxTokens,temperature) (workbench.Prediction,error).
- Python IPC JSON lines: `op: load` with graph (object), selection (saved DataSelection object), weightsPath (owned private cache file), format (`pt`/`safetensors`) -> {ok:true,input: CheckpointInput,chatCompatible,device}; `op: predict` with prompt (already User:/Assistant: framed for text), features (map), imageBase64,temperature,maxNewTokens -> {ok:true,text?/value?/label?/scores?,device,truncated?}; `op: close` or EOF exits. Failures -> {ok:false,error:actionable string}. Each response is one bounded line; logs stay stderr. CPU first is acceptable. Native runtime discovery uses UMCODE_WORKBENCH_PYTHON or UMCODE_HOME/runtimes/pytorch/bin/python.
